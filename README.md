# 🍄 Mushroom Store Manager

Sistema web desenvolvido em **PHP** para gerenciamento completo de uma loja de cogumelos, focado em organização, eficiência e praticidade no dia a dia.

---

## 📌 Sobre o Projeto

Com o crescimento da demanda por alimentos naturais, os **cogumelos** vêm se destacando como uma opção saudável e versátil. Pensando nisso, este projeto foi criado para oferecer uma solução simples e eficiente para o gerenciamento de uma loja especializada nesse segmento.

Este sistema foi desenvolvido como um **projeto acadêmico**, com o objetivo de aplicar conceitos práticos de desenvolvimento web e organização de sistemas reais.

---

## 🚀 Funcionalidades

* 📦 **Gestão de estoque**
* 💰 **Registro de vendas**
* 👥 **Controle de clientes**
* 🧾 **Organização de produtos**
* 📊 **Base para relatórios futuros**
* 🔐 Estrutura pronta para autenticação

---

## 🛠️ Tecnologias Utilizadas

* PHP (puro)
* HTML5
* CSS3
* (Opcional) JavaScript

---

## 🧠 Objetivo

O objetivo principal é fornecer um sistema funcional que:

* Simplifique as operações diárias de uma loja
* Organize informações de forma clara
* Sirva como base para evolução futura (como APIs ou sistemas maiores)
* Ajude no aprendizado prático de desenvolvimento web
